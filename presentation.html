Process

How It Works

A sequential workflow where each agent builds on the previous one's work

1

Directory Scanning

The system starts by recursively scanning the specified Java project directory, locating all .java files for analysis.

2

Code Review Analysis

The Code Reviewer agent reads all Java files and identifies bugs, anti-patterns, performance issues, and best practice violations.

3

Security Vulnerability Scan

The Proposal Writer scans for security threats including SQL injection, command injection, hardcoded credentials, and weak cryptography.

4

Report Generation

The Summary Writer synthesizes all findings into a comprehensive markdown report with executive summary and detailed analysis.

5

Output Delivery

The final report is saved to the output directory, ready for review with categorized findings and prioritized recommendations.
