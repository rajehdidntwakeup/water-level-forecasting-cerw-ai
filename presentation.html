The Challenge

Water levels on the Danube fluctuate due to rainfall, snowmelt, upstream discharge, and backwater effects. Official forecasts exist but lack spatial detail and AI-driven bias correction.

Goal: Build an AI forecasting system that predicts water levels at Korneuburg (Danube, Austria) across horizons from +1h to +168h, and verify against official hydrological forecasts.

Data Sources — Where the Data Comes From

🇩🇪 Pegelonline (WSV)

https://www.pegelonline.wsv.de/webservices/rest-api/v2

  • Water level (W) — cm, 15-min intervals
  • Discharge (Q) — m³/s
  • Water temperature (WT) — °C
  • Official forecast (WV) — verification baseline

  • Historical data via CSV/JSON export

🇦🇹 eHYD / DORIS (Austria)

https://ehyd.gv.at

  • Historical water levels at Austrian gauges
  • Discharge data (m³/s)
  • Characteristic values (MW96, flood warning levels)
  • Primary: Korneuburg (ID 207273)
  • Upstream: Linz-Donau (ID 207070)
  • Alternative: Wien / Reichsbrücke (ID 207237)

🌤️ Open-Meteo

https://api.open-meteo.com / https://archive-api.open-meteo.com

  • Precipitation (rainfall mm/h, mm/day)
  • Temperature (min/max/mean °C)
  • Snowfall & snow depth (cm)
  • Surface pressure (hPa)
  • Historical archive + forecast API
  • Free, no API key (non-commercial)

How Forecasting Happens — Model Architecture

Tier 1: Baselines (Must-Have)

Persistence: water_level(t+h) = water_level(t) — simplest anchor

ARIMA: classical time-series on same-station history

Linear Regression: multivariate on lagged levels + upstream + rainfall

Tier 2: Main AI Models (Should-Have)

XGBoost / LightGBM: gradient-boosted trees on tabular features. Handles heterogeneous inputs. SHAP interpretability.

LSTM (Seq2Vec): recurrent network over sliding windows. Captures sequential memory of rainfall antecedents. Optional attention layer.

Stacked Ensemble: XGBoost (tabular) + LSTM (sequential) → meta-learner

Tier 3: Advanced (Could-Have)

Temporal Fusion Transformer (TFT), N-BEATS / N-HiTS

Stratified Evaluation

We don't just report average metrics — we evaluate per regime:

By flow regime: low water → normal → elevated → warning → alert

By season: winter → spring melt → summer storms → autumn

By upstream: with vs without upstream rainfall events

Benchmark Targets

The AI must beat both:

1. Persistence baseline — predict current value

2. Official forecast (WV) — the real benchmark

If it can't beat either, it's not adding value.
